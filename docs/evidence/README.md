# Verification evidence

This directory contains only privacy-safe, reproducible product evidence. It must not contain candidate CVs, job URLs tied to a person, application IDs, recruiter messages, provider credentials, raw session transcripts, local runtime receipts, or unreviewed model-provider evidence.

- `providers/` records model-gateway contract evidence; quota and physical-model provenance remain UNKNOWN.
- `integration/` records test and recovery evidence, not live application outcomes.
- `reviews/` records verdicts without claiming physical reviewer-model provenance.

Raw run receipts and private evidence remain in ignored local data/session storage. Do not commit them as a shortcut to a green verification record.
